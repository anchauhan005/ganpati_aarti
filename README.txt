GANPATI AARTI - SETUP

1. Open the assets folder.
2. Replace music1.mp3, music2.mp3, music3.mp3, music4.mp3 with your four prayer files.
3. Keep the exact filenames (or edit the src values in script.js).
4. Open index.html in a browser, or deploy the whole folder to Vercel/Netlify/GitHub Pages.

Features:
- Automatic one-by-one playback
- Play / Pause / Previous / Next
- Clickable playlist
- Progress and time display
- Responsive divine dark-gold design
- No external libraries or network dependencies


Controls: Previous, Skip -10 seconds, Play/Pause, Skip +10 seconds, Next. The next prayer starts automatically when the current prayer ends.
